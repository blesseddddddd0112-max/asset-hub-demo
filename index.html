第一次使用？查看安装步骤
  1. 下载插件 ZIP 并解压。
  2. 在 Chrome 打开 chrome://extensions，开启开发者模式，选择“加载已解压的扩展程序”，选中解压目录。
  3. 刷新本页，在 Pinterest 等网页上悬停图片，选择收集；批量选择后点击保存。

这是公开预览版，尚未上架 Chrome 商店。支持图片及直接可下载的 MP4 / WebM；不支持 DRM、直播或分段流媒体。AI 反解与 Pinterest 授权同步尚未在公开版开放。

隐私说明

此演示页面不提供账号、云同步、统计或广告。素材文件与来源链接存于当前站点的浏览器 IndexedDB，其他访客无法读取。

插件在网页内识别图片和视频，只有你主动收集的文件及来源信息才会保存到扩展队列和自己的浏览器资产库。采集会向原素材网站请求文件，受该网站规则约束。网站托管方 GitHub 可能处理常规访问日志。

本预览版不调用模型服务，不收集 API Key。移除插件不会删除网页资产库中的素材；浏览器站点设置可清除本站数据。
