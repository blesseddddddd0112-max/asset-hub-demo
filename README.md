# Asset Hub public preview

Independent public demo. Visit index.html through HTTPS or a localhost web server. Assets are stored only in the current browser IndexedDB. Import, filter, preview, export and restore backups are available without an account.

The download ZIP contains an unpacked Chrome extension. It targets https://blesseddddddd0112-max.github.io/asset-hub-demo/ and supports collecting images and direct MP4/WebM files. AI reverse generation and Pinterest OAuth are not included in this static preview. This is not a Chrome Web Store release.

No internal runtime, example assets, Git history, credentials, personal asset database or model configuration is included. Do not upload .local or the parent project. Publish only this directory after review. Developer-mode installation is an interim testing method, not a substitute for store review.
