Asset Hub Collector 隐私政策

生效日期：2026 年 11 月 13 日 · 适用于公开素材采集版本

Asset Hub Collector 是个人独立演示项目，不代表剪映、Pinterest 或 Google 官方。联系邮箱：blesseddddddd0112@gmail.com。

我们处理哪些数据

扩展在获准访问的网页中识别图片和视频。你主动选择采集时，会处理素材文件、素材标题、素材地址、来源页面地址、采集时间、文件类型、大小及去重校验值。扩展需要访问网页来识别可采集素材，不会建立或上传你的完整浏览历史，也不读取密码、支付信息或通讯录。

数据保存在哪里

采集队列与临时文件保存在你当前浏览器的扩展存储中；保存到资产库后，文件与来源信息保存在资产库站点的浏览器 IndexedDB 中。不同访客的数据不共享。此版本没有账号、服务器资产存储或跨设备同步。

网络请求与第三方

采集会向你选择的素材网站请求文件；素材站点可能接收到常规请求信息，并按自己的规则处理。资产库由 GitHub Pages 托管，GitHub 可能处理访问网站所需的 IP 地址、浏览器信息等常规访问日志，详见 GitHub 隐私声明。当前公开版本不调用图片理解模型，不收集 API Key，不包含统计 SDK、广告或跟踪服务。

数据用途和披露

数据仅用于用户要求的素材采集、去重、预览、保存及备份。本项目不出售用户数据，不将素材或网页信息用于广告、用户画像、信用评估或模型训练，也不将其传送到开发者运营的服务。浏览器扩展商店及浏览器本身的数据处理适用其各自政策。

保留、删除与备份

本地文件保留到你主动删除或清理浏览器数据为止。可以在资产库删除单项素材，或通过浏览器站点设置清除资产库数据；卸载扩展会清除其本地队列，但不会自动清除资产库站点的 IndexedDB。备份文件下载到你选择的位置，由你自行保管和删除。清理本地数据前建议导出备份。

权限与安全

HTTP/HTTPS 网页权限用于识别和请求你选中的素材；扩展存储权限用于本地队列；脚本注入用于修复页面连接；右键菜单、定时任务与侧栏用于发起采集、恢复任务及查看进度。不绕过原站登录、付费墙、数字版权保护或下载限制。采集可能受来源网站规则和素材权利限制。

政策更新与联系

功能或数据处理方式变化时会更新此页面；如以后新增云端同步或 AI 服务，会在启用前提供相应说明。隐私问题请联系 blesseddddddd0112@gmail.com。
